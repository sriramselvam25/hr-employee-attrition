# Insights & Recommendations

All employee records are synthetic.

## Decision framework
- Prioritize departments with both elevated attrition and large headcount exposure.
- Separate correlation signals from causal claims; risk score is a portfolio heuristic, not an HR decision engine.
- Review overtime, engagement, satisfaction and short-tenure concentrations together.
- Use high-risk counts for workload prioritization, never automatic employment decisions.

## Actions
Create department-level retention reviews, manager conversations, workload checks and engagement follow-ups. Track movement over time before attributing improvement to an intervention.
