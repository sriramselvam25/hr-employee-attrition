# Interview Walkthrough

**Problem:** HR leadership needs to understand where attrition concentrates and which workforce signals merit investigation.

**Approach:** I created a 5,000-record synthetic workforce model, derived tenure/risk bands in Power Query and built DAX for headcount, attrition, tenure, engagement, satisfaction and risk.

**Design:** the report progresses from workforce overview to attrition diagnostics, department/employee insights and action prioritization.

**Responsible analytics:** the risk score is explicitly illustrative and must not be used to make automated employment decisions.
